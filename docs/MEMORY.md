## 不变量

- 能力声明必须区分静态核对、单测、构建、模拟、真机与真实发送。
- 不硬编码会漂移的测试数量、第三方模型名或 UI 选择器结论；确需记录时标注验证日期和环境。
- 不在示例中写真实 Token、联系人、聊天正文、绝对用户路径或截图。
- `新手指南.md` 使用非技术语言；专项开发文档可以使用实现术语。
- iOS 文档必须明确普通沙盒 App 的能力边界。
- README、模块文档和专项文档之间用链接分层，不复制整段内容形成多个事实源。
- 改行为时同步更新相关文档；只改文案时不得暗示能力已经实现。

## 模块文档体系

每个一级模块有：

- `MEMORY.md`：agent 入口、约束、影响面和验证。
- `README.md`：开发者模块地图和使用入口。

本目录的专项文档承接跨模块流程、部署和限制。根 `MEMORY.md` 只负责路由。

## 验证

- 检查相对链接目标存在。
- 检查命令与当前文件、参数和构建配置一致。
- 检查能力结论能由当前源码、测试或明确的环境证据支持。
- 检查 Markdown 无尾随空白、秘密模式和重复冲突说明。
